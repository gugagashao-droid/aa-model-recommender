## 静态覆盖结论

- 正例 T01—T03、T06、T07 的原话均能在 description 触发词或场景短语中找到直接对应,覆盖分析通过。
- near-miss T04、T05、T08 的意图未落在 description 触发词内,边界分析通过。
- 以上全部是静态分析,**没有一条在真实 harness 里跑过**,实际是否触发仍未验证。
- T05 属潜在扩展场景(文娱创作排名),按需求确认未纳入本技能范围,保持不触发是有意边界。

## 待补的真实实测

以下项在本环境无法完成,需在可观察技能自动加载的 harness 中补测:

1. 每条用例使用独立对话、真实用户口吻,不发送评测规则或预期答案。
2. 记录技能是否被加载、实际回复与产物,给出可复核证据。
3. 正例应全部触发、near-miss 应全部未触发;若失败,补 description 触发语并重跑全部用例。
4. 选择一个典型任务做"不带技能 / 带技能"基线对比,确认带技能输出存在可观察增量。
